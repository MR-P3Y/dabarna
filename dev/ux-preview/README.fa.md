# پیش‌نمایش امن UI/UX دبرنای طوفان

این مسیر مختص توسعه است و به Backend، دیتابیس، Redis، Telegram Bot، کیف پول یا API واقعی وصل نمی‌شود. `index.html` از `styles.css` و `ux-v2.css` فعلی استفاده می‌کند و داده‌های بازی‌ها/کارت‌ها صرفاً نمایشی هستند. این صفحه نباید بخشی از مسیر وب عمومی مینی‌اپ باشد.

## اجرای سرور پیش‌نمایش روی NODE2

```bash
cd /opt/davarna-v2
git switch feature/ui-ux-refresh-tambola-v2-20261106
git pull --ff-only origin feature/ui-ux-refresh-tambola-v2-20261106

# از ریشه مخزن، بدون اتصال شبکه داخل تست
docker run --rm --network none \
  -v "$PWD:/repo:ro" -w /repo \
  --entrypoint node node:22-alpine \
  backend/tests/js/test_ux_preview_safety.mjs

bash dev/ux-preview/start.sh
```

اسکریپت فقط فایل‌های عمومی CSS، فونت، لوگو و نمونه نمایشی را در مسیر موقت کپی می‌کند و Python HTTP Server را **فقط روی `127.0.0.1:19090`** اجرا می‌کند. برخلاف ارائه کل پوشه مخزن، فایل‌های تنظیمات، سورس Backend یا کلیدها اصلاً در ریشه سرور پیش‌نمایش کپی نمی‌شوند. این سرور به شبکه عمومی منتشر نمی‌شود.

## دیدن روی مرورگر کامپیوتر

در Windows PowerShell، در پنجره‌ای جدا اجرا کنید (ترمینال باید باز بماند):

```powershell
ssh -N -L 19090:127.0.0.1:19090 root@91.107.249.26
```

سپس این آدرس را در مرورگر همان سیستم باز کنید:

`http://127.0.0.1:19090/index.html`

حالت موبایل را با DevTools و عرض‌های ۳۲۰، ۳۶۰، ۴۳۰ و ۷۶۸ پیکسل، سپس اندازه دسکتاپ ۱۲۸۰ بررسی کنید. تغییر پوسته، رفت‌وبرگشت بین تب‌ها، دکمه ورود/کارت‌ها و اسکرول به بخش زنده در پیش‌نمایش شبیه‌سازی می‌شوند. اقدامات مالی عمداً غیرفعال‌اند.

## توقف بدون اثر روی Production

```bash
cd /opt/davarna-v2
bash dev/ux-preview/stop.sh
```

## محدودیت‌ها

- این **پیش‌نمایش دیداری و شبیه‌سازی دکمه‌هاست**، نه آزمون یکپارچه در تلگرام.
- برای تست واقعی تلگرام به محیط Staging با HTTPS، داده‌ها و اعتبارنامه‌های آزمایشی و سرویس‌های جدا نیاز است. نباید Production DB یا کلیدهای اصلی را کپی/متصل کرد.
- برای تأیید انتشار، تست‌های Bot/Backend، رفتار واقعی `app.js`، اعلان‌های گروه، دسترسی نقش‌ها، خطاهای شبکه و نمایش روی گوشی واقعی هم لازم‌اند.
