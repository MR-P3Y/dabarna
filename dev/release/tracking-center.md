# مرکز پیگیری

بازیکن و مدیر از دکمهٔ «پیگیری» در هدر مینی‌اپ وارد می‌شوند. جست‌وجو با کد کامل رسید، شمارهٔ داخلی، شمارهٔ کوتاه بازی، ترکیب «بازی/شماره کارت»، کد رمزارز، هش تراکنش و نام کاربری انجام می‌شود. شمارهٔ مبهم چند نتیجه می‌دهد. تاریخ فیلترها میلادی و مرز روز در API به وقت UTC است.

سوابق مرتبط با فیلتر نوع و وضعیت و تاریخ، در صفحه‌های ۲۰تایی ارائه می‌شوند. لینک پرونده در fragment صفحه ذخیره می‌شود و پس از ورود دوباره مجوز آن بررسی می‌شود. جست‌وجوهای اخیر در همان نشست مرورگر و برای هر حساب جدا هستند. خلاصهٔ قابل کپی شامل نوع، کد، وضعیت و مبلغ است.

بازیکن اطلاعات خودش را می‌بیند. مالک و نقش FINANCE_ADMIN دسترسی مالی دارند. نقش‌های ADMIN و GAME_OPERATOR می‌توانند بازی‌های تحت مدیریت خود، کارت‌ها و شرکت‌کنندگان آن‌ها را ببینند. اطلاعات مالی سایر کاربران برای نقش بازی ارائه نمی‌شود. سوابق اقدامات مدیریتی فقط برای سوپرادمین نمایش داده می‌شوند. payload خام Audit و رویدادهای سایر برندگان در پاسخ وجود ندارند.

APIهای جدید GET هستند. مسیرهای جست‌وجو و پرونده در زیر /mini-api/tracking/ قرار دارند. پاسخ‌ها private, no-store دارند. فایل‌های رابط جدید tracking.mjs و tracking.css هستند. بک‌اند معمولی از app.main این router را ثبت می‌کند.

در معماری فعلی Production، سرویس رابط جداگانه با entrypoint بدون lifespan استفاده می‌شود. برای استقرار، image جدید از image قبلی رابط ساخته شود و entrypoint علاوه بر مسیر بازی‌های شخصی، router پیگیری را ثبت کند. مسیرهای صفحهٔ مینی‌اپ، فایل‌های تغییرکرده و /mini-api/tracking/ در Nginx به listener جدید هدایت شوند. مسیرهای باقیمانده طبق تنظیم موجود ادامه دارند. کانتینر قبلی رابط برای بازگشت حفظ شود.

قبل از جابه‌جایی ترافیک، hash فایل‌ها، سلامت listener، پاسخ ۴۰۱ بدون نشست، جست‌وجوی مجاز و وضعیت چهار سرویس اصلی بررسی شود. برای بازگشت، نسخهٔ ذخیره‌شدهٔ تنظیمات Nginx بازیابی و پس از nginx -t یک reload انجام شود. هنگام انتشار یکپارچهٔ بعدی، پس از بررسی همین فایل‌ها و APIها روی بک‌اند جدید، مسیرها به آن منتقل شوند.

راستی‌آزمایی این تغییر شامل آزمون‌های مالکیت و نقش، چند نتیجهٔ هم‌شماره، صفحه‌بندی، کد فارسی، هش رمزارز، دادهٔ ناسازگار کارت، حذف اطلاعات حساس، قطع ارتباط و تعویض حساب است. سناریوهای مرورگر از API آزمایشی استفاده می‌کنند. آزمایش روی گوشی واقعی داخل Telegram هنوز انجام نشده است.
