## مرز آمادگی و برنامه انتشار

ساخت، تست وایجاد PR انجام می‌شود؛ تأیید Merge/Production در این دور داده نشده است. برای بخش زمان‌بندی [برنامه Deploy وRollback](../autopilot-pacing-20261113/report.md) و برای مالی [محدودیت‌ها وتطبیق تاریخچه](../crypto-current-20261112/history-followup-20261113.md) لازم‌الاجرا هستند.

ترتیب پیشنهادی: بازبینی مالی روی53 وdiff نهایی؛ تأیید SHA/image دقیق؛ backup خصوصی؛ بررسی دوباره وضعیت زنده وپنجره بدون بازی RUNNING؛ اجرای0013 تحت مسیر DBA با توقف هماهنگ نویسندگان فقط پس ازتأیید؛ تعویض imageهایBackend/Bot، کنترل health/RBAC/hash/flags؛ مشاهده چرخه طبیعی. مقصد واقعی واریز با انتشار برنامه تغییر نمی‌کند وفعال‌سازی آن یک عملیات مستقل با تأیید مشخص مالک است. هیچMigration/Restart/تغییرآدرس یا مالی درProduction توسطاین نامزد اجرا نشده است.

Rollback schema بعد ازثبت سرعت2/3/4 عمداً مسدود است؛ حذف تاریخچه مجاز نیست. بازگشت مالی بعد ازrotation واقعی باید صدور invoice را متوقف وscan مقصدهای قدیم/جدید وsnapshotها را حفظ کند؛ خاموش‌کردن کورکورانه versioned routing مجاز نیست. این مسیرهای حساس واقعی، آزمون زنده شده ادعا نمی‌شوند.

باقی‌مانده انتشار: تأیید مستقل مالی وMigration، انتقال/تأییدImage رویسرور، rollout کنترل‌شده و مشاهده چرخه طبیعی نسخهجدید. آزمون فشار طولانی، اختلال واقعی provider/Telegram وفعال‌سازی واقعی مقصد انجام نشده‌اند. شماره‌گذاری کوتاه پیشنهاد جدید است و مانع استفاده ازنسخه موجود محسوب نمی‌شود.
