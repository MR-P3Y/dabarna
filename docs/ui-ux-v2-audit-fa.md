## یافته‌های اثبات‌شده از ممیزی سورس
1. پوشه `frontend/` در این ورک‌تری وجود ندارد. رابط کاربری کاربر در `backend/app/static/mini/index.html`, `styles.css`, `app.js` قرار دارد.
2. فایل‌های UI بزرگ و تک‌فایلی هستند: JavaScript تقریباً ۸۹۱۹ خط، CSS تقریباً ۷۶۸۴ خط، HTML تقریباً ۱۰۴۵ خط. تفکیک اجزا در فازهای بعدی، بدون شکستن API ضروری است.
3. ناوبری `switchToView` قبلاً تنها کلاس `active` را تغییر می‌داد و نشانگر دسترس‌پذیری `aria-current` / `aria-hidden` را همگام نمی‌کرد.
4. اعلان مدیریتی بدون مجوز، به‌اشتباه نمای کیف پول را باز می‌کرد. مسیر ورود از اعلان بازی/کارت به صفحه زنده، اسکرول به بخش انتخاب‌شده نداشت.
5. دکمه آرشیو برندگان ربات برای هر قانون، عنوان ثابت «تورنا | تمام» داشت؛ برای `FULL_CARD` نادرست است.
6. نمای تک‌کارت در دسکتاپ می‌تواند به یک طرف بچسبد؛ کارت ۳×۹ در موبایل کوچک به خوانایی بهتر نیاز داشت.

## تغییرات موج ۱ (شاخه توسعه، بدون انتشار روی Production)
- `ux-v2.css`: لایه طراحی مستقل برای فاصله‌ها، خوانایی، دکمه‌های قابل لمس، فوکوس، واکنش‌گرایی، ناوبری و وسط‌چینی تک‌کارت.
